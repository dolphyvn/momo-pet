## Findings

### MAJOR — none.

### MINOR-1 — Token-purity carve-out is file-granular: a genuine UI color hex added *inside* the two carved files would be excused
- **Evidence:** `TokenPurityTests.swift:46–52` routes the two files into `nonColorHitsByName` regardless of *what* the hex is; the non-vacuity pins (`:68–71`) assert only "≥1 hex present" and "file present", so they prevent a dead/renamed-away carve-out but cannot distinguish an algorithm constant from, say, a future `0xFF00FF` pasted into `SHA256.swift`. The R4 invariant ("hex only in the palette files") is genuinely narrowed for exactly these two files.
- **Adjudication: ACCEPT as a documented deviation — no change required now.** The necessity is reproduced (72+3 literals otherwise flagged); the alternative of relocating the constants is a red herring — they must live in `SHA256.swift`/`SeededGenerator.swift` for the implementation, and *every* file under `Sources/` is scanned, so "a non-scanned support file" does not exist; decimal encoding was rightly rejected (destroys FIPS auditability); the mechanism mirrors the scanner's existing palette carve-out; and the residual is a hygiene-weakening in two pure-algorithm files, not a correctness risk. A strictly stronger follow-up exists if the orchestrator wants it: replace the ≥1-hex pin with an exact-literal allowlist (the 75 constants are frozen FIPS/canonical values), which would make even a color hex fail. Recorded as optional, not required.

### MINOR-2 — Engine-purity exemption is pinned per file+pattern but not per occurrence: a second ambient `Date` read added inside `EngineClock.swift` itself would be excused
- **Evidence:** `EnginePurityScan.swift:29–33,110–115` exempts by last-path-component + literal; `EnginePurityScanTests.swift:122–130` (`exemptionIsLive`) asserts the file exists and *contains* `Date.now` — presence, not exactly-one. Probed live: `Date(timeIntervalSince1970: 0)` appended inside `EngineClock.swift` in the throwaway copy → excused (the same addition anywhere else fails — see Method 8). Not MAJOR by the orchestrator's own bar: the exemption covers exactly one file whose sole purpose is the clock, per-pattern (randomness verified still banned inside it), and a second file named `EngineClock.swift` breaks the count==1 assertion.
- **Suggested (optional) hardening:** change the live-exemption pin to "exactly one `Date`-family occurrence in `EngineClock.swift`" — two lines — so a future stray ambient read in that file also fails.
